⚠ Chưa cấu hình API Key

Để dùng AI Advisor, bạn cần API key. Khuyên dùng Google Gemini (miễn phí). Vào tab Cài Đặt để nhập key.

Cách lấy API key:
• Google Gemini (FREE — khuyên dùng): Vào aistudio.google.com/apikey → Create API key. Miễn phí 1500 requests/ngày.
• Anthropic (Claude): Vào console.anthropic.com → API Keys → Create Key. Cần nạp credit.
• OpenRouter: openrouter.ai → Keys → Create. Hỗ trợ nhiều model AI.

Key được lưu trên trình duyệt của bạn, không gửi đi đâu khác ngoài API gốc.

Đồng Bộ Dữ Liệu (Supabase Realtime)
☁ Supabase Cloud Sync

Đồng bộ realtime giữa tất cả thiết bị. Sửa trên điện thoại → laptop tự cập nhật trong 1 giây. Miễn phí 500MB.

Setup nhanh (~5 phút):
1. Tạo tài khoản miễn phí tại Supabase
2. Tạo project + 1 bảng database
3. Copy 2 thông tin: URL + Anon Key
4. Paste vào ô bên dưới → Done
▸ Hướng dẫn chi tiết từng bước
Bước 1: Đăng ký Supabase
  1. Vào supabase.com → Start your project
  2. Sign up bằng GitHub hoặc email (miễn phí)
Bước 2: Tạo Project
  1. Nhấn "New Project"
  2. Name: dca-short
  3. Database Password: nhập 1 chuỗi nào đó, LƯU LẠI ai biết được không quan trọng vì bạn không dùng đến đâu
  4. Region: chọn Singapore (gần VN nhất)
  5. Pricing Plan: Free → Create new project
  6. Đợi 1-2 phút để Supabase setup xong
Bước 3: Tạo bảng database
  1. Trong project, vào menu trái: SQL Editor (icon </>)
  2. Bấm "New Query" → paste đoạn SQL ở dưới → bấm "Run" (Ctrl+Enter)
-- Tạo bảng lưu trữ
create table if not exists dca_data (
  id text primary key default 'main',
  payload jsonb not null,
  device_id text,
  updated_at timestamptz not null default now()
);

-- Bật Row Level Security với policy mở (vì chỉ dùng cá nhân)
alter table dca_data enable row level security;

create policy "Allow all with anon key" on dca_data
  for all using (true) with check (true);

-- Bật Realtime cho bảng này
alter publication supabase_realtime add table dca_data;
Bước 4: Lấy URL + Key
  1. Menu trái: Project Settings (icon bánh răng) → API
  2. Copy Project URL (dạng https://xxx.supabase.co)
  3. Copy anon public key (chuỗi dài bắt đầu bằng eyJhbGc...)
  4. Paste cả 2 vào form bên dưới
⚠ Lưu ý bảo mật: Anon key OK để paste vào client app. KHÔNG paste service_role key (key kia rất nguy hiểm nếu lộ).
